Movie Guide Portal
A movie exploration platform where users can discover trending movies, search films, view details, manage a watchlist, and explore actor/director profiles.

Features

* Movie Search
* Movie Grid Display
* Detailed Movie Information
* User Review Submission
* Personal Watchlist
* Trailer Video Simulation
* Movie Recommendations
* Actor & Director Profiles

How the Project Works

* Users can search movies by name, genre, or year.
* Movies are displayed in a responsive grid layout.
* Clicking a movie opens detailed information like cast, ratings, and description.
* Users can add or remove movies from their personal watchlist.
* Reviews and ratings can be submitted for movies.
* Similar movie recommendations are shown based on genre and popularity.
* Actor and director profiles can also be explored.
